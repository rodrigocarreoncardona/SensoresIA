# Predicción de datos de sensores con IA

## 💻 Instalación
Requerimientos: Python 3.13.13 o más reciente.

**1.- Clonar repositorio**
```bash
git clone https://github.com/rodrigocarreonc/SensoresIA.git
cd SensoresIA
```

**2.- Instalar dependencia para analisis**
```bash
pip install pandas numpy scikit-learn openpyxl
```

**3.- Ejecucion**
```bash
python app_prediccion.py
```

## Estructura del proyecto

```
SensoresIA/
├── app_prediccion.py
├── base_datos_sensores.py
├── data
```
